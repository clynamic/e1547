## 功能

- 跨平台（Android、iOS）
- 浏览帖子与图集

- 下载图片

- 多账号登录
- 多应用主题

### 证书指纹

如需验证下载的 APK 文件的真实性，可以核对签名证书指纹：

- **SHA1：** `8B:4B:8C:D7:FF:D6:04:DB:36:69:1B:D2:1A:BD:0E:54:0A:95:C8:28`
- **SHA256：** `8D:32:4E:43:4B:97:5A:A3:38:A7:A9:C7:F3:07:7E:1F:C0:DB:F1:30:3E:C5:D9:B9:63:4F:E8:3E:9D:DB:63:80`

可使用 [AppVerifier](https://github.com/soupslurpr/AppVerifier) 之类的工具。

## 安装

### 在 Android 上安装

- 通过 [Google Play 商店](https://play.google.com/store/apps/details?id=net.e1547)安装

或

1. 下载[最新 APK](https://github.com/clynamic/e1547/releases/latest)
2. 在 Android 设备上用文件管理器打开
3. 点击安装

#### 使用 Obtainium

1. 从 [F-Droid](https://f-droid.org/en/packages/dev.imranr.obtainium.fdroid/) 或其 [GitHub](https://github.com/ImranR98/Obtainium) 安装并打开 Obtainium
2. 点击底部抽屉的 "Add app"
3. 将 https://github.com/clynamic/e1547/releases/ 粘贴到 "App source URL*" 输入框
4. 点击 App source URL 输入框旁的添加按钮
5. 在随后的菜单中点击安装按钮

#### 应该下载哪个 APK？

- 较新的手机（2019 年及以后）→ `e1547-arm64.apk`
- 较旧的手机 → `e1547-armv7.apk`
- 还是装不上？→ `e1547-universal.apk`

### 在 iOS 上安装

应用未上架 AppStore。

- 按照 [Sideloadly](https://sideloadly.io/) 的说明操作

或

- 越狱设备后直接安装 [IPA](https://github.com/clynamic/e1547/releases/latest)

## 编译

你可以从源码编译应用：

1. 安装 [Flutter](https://flutter.dev/docs/get-started/install)
2. 克隆本 GitHub 仓库
3. 运行 `flutter build <file>`，其中 `<file>` 为 `apk` 或 `ipa`
